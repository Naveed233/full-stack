# 0.6 — New note in the single-page app

All request paths start with `https://studies.cs.helsinki.fi/exampleapp`.

```mermaid
sequenceDiagram
    participant browser as Browser
    participant server as Server

    Note over browser: User enters a note and clicks Save
    Note over browser: Submit handler calls preventDefault()
    Note over browser: Create note with content and date
    Note over browser: Add note to local array and clear input
    Note over browser: Redraw notes to display the new note

    browser->>server: POST /new_note_spa (JSON: content and date)
    Note over browser,server: Content-Type: application/json
    Note over server: Add the new note to the notes array
    server-->>browser: 201 Created

    Note over browser: No redirect or page reload; no further requests
```
