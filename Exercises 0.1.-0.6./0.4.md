# 0.4 — New note diagram

All request paths start with `https://studies.cs.helsinki.fi/exampleapp`.

```mermaid
sequenceDiagram
    participant browser as Browser
    participant server as Server

    Note over browser: User enters a note and clicks Save
    browser->>server: POST /new_note (form data: note text)
    Note over server: Create note with content and date; add to notes array
    server-->>browser: 302 Found (Location: /exampleapp/notes)

    browser->>server: GET /notes
    server-->>browser: HTML document
    browser->>server: GET /main.css
    server-->>browser: CSS file
    browser->>server: GET /main.js
    server-->>browser: JavaScript file

    Note over browser: Execute JavaScript to fetch notes
    browser->>server: GET /data.json
    server-->>browser: JSON containing all notes, including the new note
    Note over browser: Execute callback to render notes
```
